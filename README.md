# geyser-icemaker-client
Front end for icemacker controller with Esp32S3
Steps for a new front end:
Create the repository on github
Create the directhory on therm and copy all the files.
open powershell on that directory
git the following commands on reverse order (use the repository name on the link)
>> git push -u origin main
>> git remote add origin https://github.com/termic1/geyser-icemaker-client.git
>> git commit -m "Initial Ice Maker frontend"
>> git branch -M main
>> git init
